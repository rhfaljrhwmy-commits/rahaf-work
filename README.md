# معرض أعمالي | رهف عبدالرحمن

موقع معرض أعمال شخصي (Portfolio) احترافي ومتجاوب باللغة العربية، تم تصميمه وتطويره بواسطة مطورة ومصممة مواقع ويب.

## الفكرة

الموقع مخصص لعرض أعمال رهف عبدالرحمن كمطورة ومصممة ويب، ويهدف إلى:

- إظهار المهارات التقنية المتنوعة في تطوير الويب.
- تقديم أعلى ٣ مشاريع تم تنفيذها بشغف وإتقان.
- بناء حضور رقمي مهني يجذب العملاء والشركاء المحتملين.
- تقديم تجربة مستخدم عربية كاملة (RTL) وسريعة ومتجاوبة على جميع الأجهزة.

## المميزات

- تصميم عصري وأنيق بألوان هادئة (أزرق فاتح، أبيض عاجي، بنفسجي فاتح).
- واجهة عربية كاملة من الاتجاه من اليمين إلى اليسار (RTL).
- تصميم متجاوب لجميع الشاشات (هواتف، أجهزة لوحية، أجهزة سطح المكتب).
- شريط تنقل علوي متجاوب مع قائمة جانبية للهواتف.
- قسم ترحيبي يعرّف بنفس المهارات.
- قسم مشاريع بثلاث بطاقات مع أزرار معاينة.
- قسم المهارات مع مؤشرات تقدم تفاعلية.
- قسم تواصل معي مع نموذج رسالة.

## التقنيات المستخدمة

- HTML5
- CSS3 (مع تقنيات Flexbox و Grid)
- JavaScript (أساسي للتنقل)
- Google Fonts (Cairo)

## التشغيل

لا يحتاج أي خادم خاص، يمكن فتح ملف `index.html` مباشرة في المتصفح أو وضع الملفات في أي خادم ويب مثل XAMPP أو Nginx.
